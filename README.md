# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty `u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9`.

## What it does

`main.py` (Python 3, standard library only, no network) writes one line —
the GPS's own excuse for sending the driver down the wrong road — to
`/output/entry.txt`.

The line:

> The map promised a shortcut, and the lake was supposed to have a bridge — I checked twice.

90 characters, a single line of plain UTF-8 text. The GPS speaks in its own
voice: smug and defensive, blaming the map, with one concrete image (the
lake that was supposed to have a bridge) and the turn landing in the last
few words.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt`. The output directory is created at the start of
the program; it is never deleted.
